# 🌟 Radiant Emotions AI

AI-powered mental wellness and emotion support platform designed to provide interactive emotional assistance, intelligent suggestions, and a seamless user experience through a modern full-stack web application.

---

# 📌 Problem Statement

Mental health challenges such as stress, anxiety, loneliness, and emotional imbalance are increasingly common among students and young adults. However, many people do not have access to instant emotional support systems that are affordable, accessible, and available 24/7.

Radiant Emotions AI aims to bridge this gap by creating an AI-powered emotional wellness platform that helps users interact, express emotions, and receive supportive responses in real time.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Bharathwajpm/radiant-emotions-ai.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd radiant-emotions-ai
```

---

## 3️⃣ Install Frontend Dependencies

```bash
npm install
```

---

## 4️⃣ Run Frontend

```bash
npm run dev
```

Frontend runs at:

```bash
http://localhost:5173
```

---

## 5️⃣ Run Backend

```bash
cd backend
npm install
npm start
```
